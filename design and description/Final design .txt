' ---------- Relationships ----------
UI "1" --> "1" VoleMachine : controls
VoleMachine "1" *-- "1" CPU : contains
VoleMachine "1" *-- "1" Memory : contains
CPU "1" *-- "1" Register : owns
CPU "1" *-- "1" ALU : owns
CPU ..> Memory : fetches / reads / writes

' ---------- Notes ----------
note right of Memory
  256 cells ("00".."FF"), 8 bits each.
  Plain storage; knows nothing about the screen.
  All hex values are uppercase.
end note

note right of Register
  16 registers (R0..RF), 8 bits each.
end note

note right of CPU
  IR is 4 hex digits ("0000" initially).
  Fetch reads 2 cells, advances PC by 2;
  throws if PC > FE.
  Execute decodes IR and checks isValidInstruction;
  throws if invalid. Handles opcodes 1-4, B, C;
  calls ALU for 5-A. ALU errors pass through.
  STORE to FF also appends the raw value to 'screen'.
  'screen' is the single output buffer for the machine.
  reset() clears PC, IR, halted, screen and registers.
end note

note bottom of ALU
  opCodes = valid codes "1".."C".
  Float: 8-bit (1 sign, 3 exponent excess-four, 4 mantissa).
  Zero = 00; encoding truncates (book rule).
  Throws if a float result is above 7.5 or
  non-zero and below 1/32.
  Two's complement add keeps the low 8 bits.
end note

note bottom of VoleMachine
  LoadFile: convert lines to uppercase, validate the whole
  file first (4 hex digits, valid opcode, even start,
  fits in memory); throw on any problem; only then
  clear memory, reset CPU, write, set PC.
  run(): step() until halted. step(): one instruction.
  reset(): calls cpu.reset() and mem.clear().
  getScreen(): returns cpu.getScreen().
end note

note bottom of UI
  Catches errors from LoadFile / run / step and
  shows the message. Screen shown as ASCII for
  20-7E, otherwise as [hex]. Converts input to uppercase.
  displayScreen() uses machine.getScreen().
  modifyRegister() and modifyMemory() allow the user
  to set values through VoleMachine/CPU/Memory accessors.
end note
